#  SIGNAL LOST

<br>

## about it

you are the night shift operartor for CERBERUS SECURITY at Site-07. you see an anomaly on CAM-04 and try to further find about it.

you just have to keep an eye on the CAMERAS and review EVERYTHING YOU SEE.

## how i made it

i made this using HTML for barebones, [Tailwind CSS](tailwindcss.com), Vanilla JS, generated audio through web audio api directly, all visuals are ascii art or made in CSS.

## how it plays

you see a monitor screen with four camera feeds which is lobby, stairwell, server room and THE PARKING LOT

- click on the camera with suspicious activity
- file the report as a good operator or dismiss it to face the consequencies of your actions
- four anomalies. one ending. the last camera is yours.
